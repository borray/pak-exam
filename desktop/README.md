# ПАК — нативная версия (.NET 8 + Avalonia)

Настоящее десктопное приложение для Windows. Без браузера/Chromium —
интерфейс рисуется напрямую (Avalonia), как у обычных программ Windows.

## Один раз установить
**.NET SDK 8.0** — https://dotnet.microsoft.com/download/dotnet/8.0
(раздел «SDK 8.0», Windows x64). После установки перезагрузить ПК.

## Запуск
Двойной клик по **«ПАК натив — Запустить.bat»** в корне проекта.
Первый запуск дольше (качаются библиотеки), потом быстро.

## Отдельный EXE
Двойной клик по **«ПАК натив — Собрать EXE.bat»** →
готовый `desktop/Pak/publish/PAK.exe` работает без .NET.

## Данные
`%AppData%\PAK\exams.json`
